# MAL-OPS

Malware analysis workbench under H3AD-DF: a 17-phase step-by-step process guide (lab setup through legal handoff) with an interactive checklist, IOC worksheet, command cheat sheet, YARA/Sigma rule builder, ATT&CK tagger, and report generator. Client-side only, no backend.

Live: https://h3ad-sec.github.io/MAL-OPS/
